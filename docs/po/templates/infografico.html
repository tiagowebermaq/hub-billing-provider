bill.collected · bill.missing · batch.sent · batch.acknowledged · HMAC-SHA256
API de leitura

Painel admin
Filas, falhas, reprocessar, alertas

Correlation ID de ponta a ponta

Gerado na entrada (API, scheduler, upload) ou lido de X-Correlation-ID
Propagado na propriedade AMQP e no envelope de cada mensagem
Presente em todos os logs JSON e na auditoria
Enviado ao sistema de aluguéis e em cada webhook
Idempotência: provider + conta + competência
